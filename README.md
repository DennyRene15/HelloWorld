Comandos utilizados

Para crear el proyecto HelloWorld con TypeScript, ejecuté el siguiente comando:

pnpm create expo-app HelloWorld –template blank-typescript

Luego, accedí a la carpeta del proyecto:

cd HelloWorld

Para instalar las dependencias, utilicé:

pnpm install

Finalmente, ejecuté el siguiente comando para iniciar la aplicación:

pnpm start

Una vez iniciado el proyecto, escaneé el código QR con mi iPhone para ejecutar la aplicación en Expo Go.
